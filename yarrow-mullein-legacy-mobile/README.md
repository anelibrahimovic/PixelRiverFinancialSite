# Yarrow–Mullein Bank — Legacy Mobile (before redesign)

A functioning but intentionally dated classroom comparison prototype. This is the **before** mobile interface, not the improved one.

Open `index.html` in Chrome or Edge. The sample access ID is prefilled (**4532 9087 1140 6621**), and the sample password is **David123**.

### Intentionally limited legacy features
- Plain login and static chequing and savings account balances.
- Manual transfer/payment **request** form. The confirmation is temporary and cannot be retrieved after leaving the screen.
- Contact information directing users to telephone Member Services or visit a branch for payment follow-up.
- No chatbot, FAQ, transaction history, proactive status updates, downloadable reporting, notifications, payment automation, scheduled/seasonal payments or real-time balance changes.

Submitting the form **does not send money or update balances**. Bank employees would have to process it manually in a real legacy workflow, and the user must phone to find out what happened.

Educational simulation only; the interface is not connected to any real financial institution or payment system.
