# Yarrow–Mullein Bank — Legacy mobile application (before redesign)

This deliberately dated **before** prototype illustrates the original banking experience and the gaps addressed by the finished mobile application. It remains functional for classroom demonstrations while intentionally omitting the redesign's proposed solutions.

Open `index.html` in Chrome or Edge, or use the identical, self-contained `standalone.html`.

**Classroom test login:** Access Card Number `4532 9087 1140 6621` (prefilled); password `David123`.

The legacy experience includes a basic member login, two static account balances, a manual transfer/payment *request* form, and telephone/branch contact instructions. Manual requests show a temporary confirmation reference only: **they do not send money, move funds, update balances, or appear in any history**. Users must contact the bank to check processing. There are no live services, no transaction history, no payment statuses/timelines, no chatbot or FAQ, no notifications, no reports/receipts, and no recurring, seasonal, or automated transactions.

This is a simulation. Never enter real credentials or financial details. Its restrictions are deliberate, so it can be evaluated alongside the improved mobile prototype.

## Added legacy help desk (manual ticketing)

The old app now includes a **Tickets** tab. It deliberately shows the cumbersome support workflow that the redesigned app is meant to improve: choose an issue and account, manually retype a transfer reference, enter a detailed description and sample phone/email, then review every field and acknowledge the wait. Only then does the app display a locally generated **YM-HELP** reference. You must manually record or print it and call Member Services to lodge/confirm the request and follow up after an illustrative **3–5 business days**. No ticket feed, transaction linkage, SMS, live status changes, chat, FAQ, automatic bank replies, or backend exist. Ticket confirmations disappear on logout, as a deliberate limitation; the app does **not** transmit forms to a real support team.
